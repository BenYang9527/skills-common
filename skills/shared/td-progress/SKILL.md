---
name: td-progress
description: 回顾当前任务的来路、目标、所处位置、已走和未走的路，并在后续回复中附上进度百分比。适用于用户要求用 td-progress 跟踪进度或回顾任务进展时。
---

用你自己的语言描述一下，你从哪里来、到哪里去，现在站在哪里？（按 1、2、3……编号排列）
已经走过哪些路，还有哪些路要走？用“里程碑｜状态”表格逐项呈现，简述每一步的结果、进展或阻碍。例如：

| 里程碑 | 状态 |
| --- | --- |
| 明确需求 | ✅ 已完成 |
| 实施方案 | 🔄 进行中 |
| 验证结果 | ⏳ 待开始 |
| 外部依赖确认 | 🚧 受阻 |

后续每次回复带一个百分比。
